# 🧠 FlowDesk — Decision Framework

---

## 1. Purpose

Defines how decisions are structured and evaluated.

---

## 2. Decision Structure

Each decision includes:

- title
- description
- rationale
- expected outcome
- linked metrics
- owner
- lifecycle state

---

## 3. Decision Quality Criteria

---

A good decision must be:

- explicit
- measurable
- traceable
- reversible (when possible)

---

## 4. Decision Evaluation

---

```text
Expected Outcome vs Actual Outcome
```

---

## 5. Decision Drift

---

```text
Expected ≠ Actual
```

→ requires review

---

## 6. Staff-Level Insight

FlowDesk transforms decisions from:

```text
Implicit → Explicit
```
