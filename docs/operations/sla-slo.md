# 🧠 FlowDesk — SLA / SLO

---

## 1. Purpose

Defines service reliability targets.

---

## 2. Definitions

- SLA → external commitment
- SLO → internal target

---

## 3. SLO Examples

---

### API Availability

- 99.9% uptime

---

### API Latency

- p95 < 200ms

---

### Projection Freshness

- < 2 seconds

---

### Event Processing Success

- > 99.99%

---

## 4. Error Budget

Defines acceptable failure rate.

---

## 5. Monitoring

- alert on SLO breaches
- track trends

---

## 6. Staff-Level Insight

SLOs define when the system is “good enough”.

Without them, everything is subjective.
